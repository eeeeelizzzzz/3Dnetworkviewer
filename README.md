# 3D Network Viewer

Interactive data viewing interface for 3D observing networks. Developed by Elizabeth Smith ([@eeeeelizzzzz](https://github.com/eeeeelizzzzz) | elizabeth.smith@noaa.gov) with Cursor support for code development.

All data come from the 2024 SCALES UAS project conducted in Oklahoma.
