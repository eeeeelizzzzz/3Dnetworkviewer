How to use the portal

Interactive case viewer for SCALES fusion states vs UAS and HRRR on the Oklahoma domain. Switch 3D Network / 2D Site in the header. Please share comments with the Feedback button (also linked here).

2D Site viewer

  • Map — domain with profiler sites. Optional plan-view field (map source + height AGL); profile time slider drives the hour. Purple = UAS this hour; gray = no obs; gold = selected. Click a site marker.
  • Time–height — Quick = OBS | HRRR (side-by-side), optional OBS − HRRR. Custom ticks add OBS, HRRR, chosen cube (A/B/C), and pairwise differences. Two panels side-by-side; three or more scroll.
  • Left panel — MetPy Skew-T (full troposphere), Skew-T low (~1050–680 hPa with UAS surface parcel + CAPE/CIN), or Plotly time series at a chosen height. Line-plot source checkboxes toggle MetPy overlays.
  • Wind panel — wind profile (speed as lines, direction as points) or hodograph. Same source checkboxes. Profile time is the slider under the map (independent of full-case time–height).
  • Analysis cube — which A/B/C volume feeds “Cube” time–height panels; overlays still use the source checkboxes.

3D Network viewer

  • Orbit — left-drag rotate; scroll zoom; right-drag (or middle-drag) pan.
  • Probe — click a profiler marker or floor point for profile, time series, and hodograph (nearby sites snap). Purple pillars = UAS at that valid time; gray = none.
  • Z height space — Flat AGL keeps the floor level; Terrain-following tilts with MSL (state outline stays flat).
  • Camera — Reset from the south (N up); W from the west; Top bird’s-eye. Compass needle points north.
  • Time — bar under the map (or Settings): scrub, play, </>. Keys ,/. (or ←/→) step one valid time. Iso-layer values stay fixed while animating.
  • Cross-section — Spatial: two ground points for a transect (Clear removes it). Time–height: field vs height at the probe across valid times.
  • Volume / terrain — multi-layer isosurfaces or horizontal slice; toggles for volume, terrain, geo, sites, domain box. Terrain opacity under Layers.

What is plotted (3D)

  • Fusion state — which 3D volume is drawn (HRRR / A / B / C). Also sets the default A/B/C series chip (you can still toggle A/B/C on profile & time series).
  • Field — 3D variable for isosurfaces/slices (colormap, vmin/vmax, contour Δ under Color scale).
  • Series variable — quantity on the profile X-axis and time-series Y-axis (independent of the 3D field unless you match them).
  • Source chips (UAS, HRRR, A, B, C) — on/off for profile, hodograph, and time series. A/B/C sample cubes at the probe; UAS from soundings.
  • Profile / Hodograph — left-pane selector. Profile = series vs height AGL. Hodograph = u (+east), v (+north) from ≥ 50 m AGL.
  • TS height AGL — extraction height for the time series.
  • Jump to site — moves the probe to that profiler.

Colors & limits

  • Color scale — colormap, vmin/vmax, contour Δ, optional map coloring of iso layers, poll cursor (height from Poll height AGL).
  • Iso layers — per-layer color (disables map coloring), typed iso value, opacity. Levels stay fixed during play.
  • Series colors — pickers next to UAS/HRRR/A/B/C (Suite 2 defaults).
  • Profile / TS axes — optional X/Y/Z limits; blank = auto. Vertical exaggeration stretches height in 3D only.

Export

  • Panels — Export menu or ⬇ on a panel → light-background PNG (profile/hodograph, time series, section; 2D Site skew-T composites visible MetPy layers).
  • 3D / plan map — viewport PNG or lon–lat plan map at poll height (with profile/hodo insets when that mode is active).

Demo data are a pre-exported case window (not a live network feed). Analyses use lagged HRRR backgrounds consistent with the volumes shown.
