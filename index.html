How to use the portal

Interactive case viewer for SCALES fusion states vs UAS and HRRR on the Oklahoma domain.

3D view

  • Orbit — left-drag to rotate; scroll to zoom; right-drag (or middle-drag) to pan.
  • Probe — click a profiler marker or any floor point to sample profile, time series, and hodograph at that location (nearby sites snap). Purple pillars = UAS obs available at that valid time; gray = no obs.
  • Z height space — Flat AGL keeps the floor level; Terrain-following tilts the surface with MSL (Oklahoma outline stays flat).
  • Camera — Reset from the south (N up); W from the west; Top bird’s-eye. Compass needle points north.
  • Time — bar under the map (or in Settings): scrub, play, or use </> buttons. Keys ,/. (or </>, or ←/→) also step one valid time. Iso-layer values stay fixed while animating.
  • Cross-section — Spatial: draw two ground points for a transect; Clear removes it. Time–height: field vs height for the active probe across all valid times (same site/grid as profile & time series).
  • Volume / terrain — multi-layer isosurfaces or a horizontal slice; toggle volume, terrain, geo, sites, and the domain scale box. Terrain opacity is under Layers.

What is plotted

  • Fusion state — which 3D volume is rendered (HRRR / A / B / C). Also sets the default A/B/C series chip (you can then toggle A/B/C freely for overlays on profile & time series).
  • Field — 3D variable for isosurfaces/slices. Use colormap, vmin/vmax, and contour Δ under Color scale for quantitative coloring.
  • Series variable — quantity on the profile X-axis and the time series Y-axis (not the 3D field unless you match them).
  • Source chips (UAS, HRRR, A, B, C) — checkboxes turn series on/off on profile, hodograph, and time series. A/B/C sample the analysis cubes at the probe; UAS comes from obs soundings. Changing Fusion state resets A/B/C to that version by default.
  • Profile / Hodograph — left-pane selector. Profile = Series variable vs height AGL. Hodograph = wind components u (+east) and v (+north) starting at ≥ 50 m AGL; rings are constant speed; open circle marks the first level above that floor.
  • TS height AGL — extraction height for the time series (slider or typed number).
  • Jump to site — sets the probe to that profiler.

Colors

  • Color scale — colormap (Viridis, Plasma, …), editable vmin/vmax, contour interval Δ + Apply to fill iso layers, optional “color layers from colormap,” and a polling cursor readout. Cursor x/y follow the pointer; sample height is set only by Poll height AGL.
  • Iso layers — color picker (disables map coloring), typed iso value, and per-layer opacity.
  • Series colors — next to each UAS/HRRR/A/B/C chip is a color picker for profile, hodograph, and time series traces (defaults follow Suite 2).
  • Terrain — monochrome elevation (black low → white high) with optional hillshade; elev. colorbar follows the Colorbars toggle and Terrain on/off.

Editable limits & values

  • Iso layer values — type the level; opacity is the slider on that row. Levels stay fixed while time plays.
  • Slice / terrain opacity — slice mode has a slice opacity slider; terrain has its own control under Layers.
  • Profile axes — Profile X min/max and Z min/max (AGL). Leave X blank for auto-range; Z defaults 0–1500 m.
  • Time series Y — optional Y min/max (blank = auto).
  • Vertical exag. — stretches height in the 3D scene only.

Export

  • Panels — Export menu or ⬇ on each panel downloads a light-background PNG (profile/hodograph, time series, cross-section / time–height).
  • Field mode — Isosurfaces / horizontal slice, or OBS profiles (fixed T·RH | WS·WD) / OBS hodographs (no volume). Click the map for a popup sample at any point.
  • 3D / 2D map — Viewport toggle. 2D shows a plan map; in profile/hodograph modes the sticks appear on the map.
  • Plan map export — lon–lat heatmap at Poll / plan-map height AGL (plus profile/hodo insets when that mode is active).
  • 3D view — PNG of the current camera (isosurfaces or tilted slice as shown). Use light background for slides; keep dark for matching the portal.

Bottom panels

  • Time series — enabled sources at TS height for the active probe across valid times.
  • Cross-section — spatial transect of the current 3D field, or time–height at the probe for the fusion-state field.

Data are a pre-exported case (not a live network feed). Innovations use lagged HRRR backgrounds consistent with the analysis volumes.
